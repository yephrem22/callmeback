# Tasks: Core Engine (intake, policy, state machine, ledger, audit)

**Input**: Design documents from `specs/003-core-engine/` (plan.md, spec.md, research.md, data-model.md, contracts/, quickstart.md)

**Tests**: Requested by the spec (FR-023, SC-009) and the constitution (VIII). Every test task names the PLAN.md vectors it asserts. Tests are written in the same phase as the code they cover; `pytest -q` must be green at the end of every phase and before every commit.

**Organization**: Four phases, exactly as plan.md "Phases". Phase 1 is the skeleton and the frozen contracts (milestone A1); it must take about an hour. Phases map to user stories: Phase 2 → US1 and US4, Phase 3 → US2 and US3, Phase 4 → US5 and the fixtures exporter (FR-022). Each phase ends with "stop and report" per constitution X.

## Format: `[ID] [P?] [Story] Description`

- **[P]**: can run in parallel (different files, no dependency on an unfinished task)
- **[Story]**: US1–US5 from spec.md; setup and cross-cutting tasks carry no label
- Paths are repository-relative. Files owned by other specs (PLAN.md §6: `Makefile`, `.env.example`, `app/api.py`, `app/pipeline.py`, `app/voice/`, `app/storage.py`, `app/agents/`, `web/` except `web/src/fixtures/`) are never created here.

## Path Conventions

Single Python project per plan.md: `core/`, `app/`, `samples/`, `scripts/`, `tests/` at the repository root.
