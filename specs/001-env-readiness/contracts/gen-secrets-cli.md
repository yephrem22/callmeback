# Contract: `scripts/gen_secrets.py`

Invoked as `make secrets`. Writes the app's own secrets into `.env` (PLAN.md §0.4 "App secrets" row, §7.1 quoting rule, §23.1).

## Arguments

| flag | default | meaning |
|---|---|---|
| `--env-file PATH` | `.env` at the repo root | file to create or update (tests pass a temp file) |
| `--rounds N` | `14` | bcrypt cost (tests pass `4` to stay fast) |
| `--quiet` | off | print only the password line |

## Behaviour

1. Read the file line by line if it exists; otherwise start empty. Never read any other file.
2. For `INTERNAL_TOKEN`, `MCP_TOKEN`, `DASH_USER`, `DASH_PASS_HASH`, in that order:
   - a line `KEY=value` whose value is valid (data-model.md "AppSecret") is left byte-for-byte unchanged;
   - a line whose value is a placeholder (`is_placeholder`, shared with `check_env.py`) is replaced in place, keeping any trailing `# comment`;
   - a missing key is appended; the first appended line is preceded by `# --- generated by make secrets (spec 001)`.
3. Values: tokens from `secrets.token_urlsafe(32)`; `DASH_USER=demo`; the password from `secrets.token_urlsafe(12)`; the hash `bcrypt.hashpw(password, bcrypt.gensalt(rounds, prefix=b"2a"))` written as `DASH_PASS_HASH='<hash>'` in single quotes.
4. Write atomically (temp file in the same directory, then rename); create with mode `0600`.
5. Print, exactly once, to stdout:
   ```
   Dashboard login: user demo, password <plain password>
   Save it now; only the hash is stored.
   ```
   and one line per variable: `INTERNAL_TOKEN: written` | `kept` | `replaced placeholder`. No token or hash is ever printed, not even masked.
6. If nothing needed writing, print `Nothing to do; all app secrets present.` and do not touch the file.

## Exit codes

- `0`: success (including nothing to do).
- `1`: the file could not be written (permissions, disk).

## Guarantees (tested)

- Second consecutive run leaves the file byte-identical and prints "Nothing to do" (SC-006).
- A valid existing value is never changed (FR-012).
- Tokens are ≥ 32 characters; the hash matches `^\$2a\$\d\d\$[./A-Za-z0-9]{53}$` and is single-quoted (FR-013).
- The plain password appears once in stdout and nowhere in the file.
